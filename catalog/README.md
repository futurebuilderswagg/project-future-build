# Тесты по темам

Каждый файл `.xlsx` в этой папке становится кнопкой в разделе «Тесты по темам». Название файла становится названием блока, например `Законы Ньютона.xlsx`.

Формат файла такой же, как у [образца](../test_template.xlsx). Чтобы блоки шли в порядке программы, начинайте названия с номера: `01 Кинематика.xlsx`.

После добавления файла пересоберите образ и перезапустите бота. Блок загружается один раз: чтобы заменить вопросы уже загруженного блока, дайте файлу новое имя.

Встроенные блоки «Механика», «Термодинамика» и «Электродинамика» заданы в `impulse/questions_data.py`.
