# Оформление бота

Положите сюда картинки с точными именами из таблицы и пересоберите образ. Если файла нет, бот отправит сообщение без картинки.

| Файл | Где показывается |
| --- | --- |
| `welcome.png` | Приветствие по команде `/start` |
| `test_done.png` | Результат после завершения теста |
| `bonus.png` | Подтверждение или отказ по заявке на бонус |
| `certificate.png` | Сертификат «Эксперт темы» |

Рекомендации: формат PNG или JPG, горизонтальная картинка 1280×720, размер файла до 2 МБ, важный текст не у самого края.

Аватар бота задаётся отдельно, в настройках бота на платформе MAX. Описание бота задано в `impulse/config.py`, константа `BOT_DESCRIPTION`.

Цвета, шрифты и форму кнопок мессенджер определяет сам, бот их менять не может.
