# 🤖 Учебный бот на MaxAPI

Простой, но функциональный чат-бот для мессенджера **MAX**, написанный на Python с использованием библиотеки `maxapi`. Бот поддерживает регистрацию и авторизацию пользователей (учителей и учеников) по ФИО и паролю, а также кеширование сессий для быстрой работы.

##✨ Возможности

- 🔐 **Регистрация и вход** по ФИО и паролю (пароли хранятся в виде bcrypt-хешей).
- 👥 **Выбор роли**: Учитель или Ученик.
- ⚡ **Кеширование сессий** в памяти на 10 минут (не нужно вводить пароль при каждом запросе).
- 🗄️ **База данных SQLite** для хранения пользователей.
- 🛡️ **Защищённые команды** (например, `/profile`), доступные только после входа.
- 🎛️ **Удобное меню** с inline-кнопками.

## 📋 Требования

- **Python 3.11** или выше.
- **pip** (менеджер пакетов Python).
- **Git** (для клонирования репозитория).
- Аккаунт в мессенджере **MAX** и **токен бота** (получается при создании бота).

## 🚀 Инструкция по запуску на другом компьютере

### Шаг 1. Клонируйте репозиторий

Откройте терминал (или командную строку) и выполните:


git clone https://github.com/ваш_логин/имя_репозитория.git
cd имя_репозитория


*Замените `ваш_логин` и `имя_репозитория` на свои данные.*

### Шаг 2. Создайте виртуальное окружение

Это изолирует зависимости проекта от системного Python.

**Windows:**

python -m venv venv
venv\Scripts\activate


**Linux / macOS:**

python3 -m venv venv
source venv/bin/activate


После активации в начале строки терминала появится `(venv)`.

### Шаг 3. Установите зависимости

Убедитесь, что вы находитесь в папке проекта (где лежит `requirements.txt`), и выполните:


pip install -r requirements.txt


> **Важно:** Если при установке возникнет ошибка, связанная с `bcrypt` и `passlib`, убедитесь, что в `requirements.txt` указана версия `bcrypt==4.0.1`. Если нет — установите её вручную:

pip install "bcrypt==4.0.1"

### Шаг 4. Настройте токен бота

В корне проекта создайте файл **`token.env`** и добавьте в него строку:


MAX_BOT_TOKEN=ваш_токен_из_кабинета_MAX


*Замените `ваш_токен_из_кабинета_MAX` на реальный токен, который вы получили при создании бота.*

> ⚠️ **Никогда не загружайте файл `token.env` в GitHub!** Он уже добавлен в `.gitignore` и не должен попасть в репозиторий.

### Шаг 5. Запустите бота


python main.py


Если всё сделано правильно, в консоли появится сообщение о запуске, и бот начнёт отвечать на команды в мессенджере MAX.

## 🎮 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и выбрать роль (Учитель / Ученик) |
| `/profile` | Показать данные текущего пользователя (только после входа) |
| `/cancel` | Отменить текущее действие (ввод ФИО или пароля) |
| `/help` | Показать справку |

## 🛠️ Возможные проблемы и решения

**1. Ошибка `ValueError: password cannot be longer than 72 bytes`**
Это конфликт версий `passlib` и `bcrypt`. Решение:

pip install "bcrypt==4.0.1"


**2. Ошибка `can't open file '/app/main.py'` при запуске в Docker**
Убедитесь, что вы собираете образ из папки, где лежит `main.py`. Команда сборки:

docker build -t my-max-bot .


**3. Бот не видит файл `token.env`**
Проверьте, что файл лежит в той же папке, что и `main.py`, и что в нём нет пробелов вокруг знака `=`.

**4. Команды не отображаются в меню MAX**
Убедитесь, что вы проверяете бота в официальном клиенте MAX (iOS, Android или десктоп), а не в веб-версии. В каналах команды не отображаются.
