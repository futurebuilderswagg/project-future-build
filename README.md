# Академический импульс

Чат-бот для мессенджера MAX, который превращает повторение школьных тем в игру с накоплением баллов. Ученик проходит тесты в удобное время, копит баллы и обменивает их на образовательные бонусы. Учитель не тратит время на проверку и получает готовый отчёт: кто справился, кому нужна помощь и какие вопросы оказались трудными.

Проект команды «Архитекторы будущего» (БОУ ОО «МОЦРО № 117», г. Омск) для хакатона «Идея Фикс» от Сферума, направление «Арена развлечений».

## Что умеет бот

**Ученик**
- вступает в класс по коду из шести цифр или по приглашению учителя;
- проходит тест в удобное время, пока он открыт: на прохождение даётся 20 минут;
- получает свой порядок вопросов и вариантов;
- копит баллы за верные ответы: 10, 20 или 30 в зависимости от сложности, и бонусы за хороший результат и серию дней;
- обменивает баллы на бонусы в «Пространстве достижений», видит уровень, звание, серию дней и значки;
- после закрытия теста получает разбор ошибок с пояснениями.

**Учитель**
- выдаёт готовые тесты по блокам программы из раздела «Тесты по темам»;
- создаёт свои тесты из Excel: они хранятся в разделе «Мои тесты»;
- выбирает, сколько тест открыт: 20 минут, 1, 3 или 7 дней;
- после закрытия теста автоматически получает отчёт: средний результат, кому нужна помощь, трудные вопросы;
- подтверждает или отклоняет заявки на бонусы.

## Быстрый запуск через Docker

Нужны Docker Engine или Docker Desktop с Linux-контейнерами и токен бота MAX.

**1.** Создайте файл настроек.

Linux и macOS:

```bash
cp token.env.example token.env
```

Windows PowerShell:

```powershell
Copy-Item token.env.example token.env
```

Откройте `token.env` и укажите `MAX_BOT_TOKEN` и `TEACHER_CODE`.

**2.** Соберите образ и создайте том для базы.

```bash
docker build -f Dockerfile -t max-school-bot:local .
docker volume create max-school-bot-data
```

**3.** Запустите контейнер.

Linux и macOS:

```bash
docker run -d \
  --name max-school-bot \
  --init \
  --restart unless-stopped \
  --env TZ=UTC \
  --mount type=volume,source=max-school-bot-data,target=/app/data \
  --mount "type=bind,source=$(pwd)/token.env,target=/app/data/token.env,readonly" \
  max-school-bot:local
```

Windows PowerShell:

```powershell
$botTokenPath = (Resolve-Path .\token.env).Path
docker run -d --name max-school-bot --init --restart unless-stopped --env TZ=UTC --mount type=volume,source=max-school-bot-data,target=/app/data --mount "type=bind,source=${botTokenPath},target=/app/data/token.env,readonly" max-school-bot:local
```

**4.** Проверьте журнал.

```bash
docker logs -f max-school-bot
```

На Linux при ошибке доступа к файлу настроек выполните `sudo chgrp 10001 token.env` и `chmod 640 token.env`.

Обновление, резервные копии и перенос базы описаны в [docs/operations.md](docs/operations.md).

## Первая проверка за 5 минут

Понадобятся два аккаунта MAX.

1. **Учитель:** откройте бота, нажмите `/start`, затем «Учитель» и «Зарегистрироваться». Введите код учителя, ФИО и пароль.
2. Нажмите «Создать класс» и введите название. Бот покажет код класса.
3. **Ученик:** со второго аккаунта зарегистрируйтесь как ученик, нажмите «Вступить по коду класса» и введите код.
4. **Учитель:** откройте «Тесты», «Тесты по темам», выберите «Механика», класс и срок.
5. **Ученик:** нажмите «Пройти тест» и ответьте на вопросы.
6. **Ученик:** откройте «Пространство достижений». Если баллов хватает, запросите бонус.
7. **Учитель:** откройте «Заявки на бонусы» и подтвердите заявку.
8. Отчёт учителю и разбор ученику приходят после закрытия теста. Чтобы увидеть их быстро, выдайте тест на 20 минут. Текущие результаты доступны в «Тесты», «Результаты тестов».

Команды бота: `/start`, `/help`, `/profile`, `/register`, `/tests`, `/create_class`, `/invite`, `/my_class`, `/join`.

## Запуск без Docker

Нужен Python 3.12. Выполните команды в папке проекта.

Linux и macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp token.env.example token.env
.venv/bin/python main.py
```

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item token.env.example token.env
.\.venv\Scripts\python.exe main.py
```

Перед запуском заполните `token.env`. База `bot.db` создаётся автоматически в текущей папке.

Проверка логики без подключения к MAX:

```bash
python -m unittest discover -s tests
```

## Настройки

Значения задаются в `token.env` или переменными окружения.

| Параметр | Обязательный | Назначение |
| --- | --- | --- |
| `MAX_BOT_TOKEN` | да | Токен бота MAX |
| `TEACHER_CODE` | рекомендуется | Код для регистрации учителя. Без него учителем может стать любой пользователь, в журнале появится предупреждение |
| `BOT_TIMEZONE` | нет | Часовой пояс дат в сообщениях, по умолчанию `Asia/Omsk` |

Цены бонусов, звания и сроки заданы в [impulse/config.py](impulse/config.py).

## Как устроены баллы и бонусы

- Баллы не являются оценкой и считаются отдельно в каждом классе.
- За верный ответ начисляется 10 баллов, умноженных на сложность вопроса (1, 2 или 3). Повторно за тот же тест баллы не начисляются.
- За завершённый тест с результатом от 80% даётся 50 баллов, за тест без ошибок 100 баллов и ещё 30 за «Снайпера».
- Серия дней приносит 100 баллов каждые 7 дней подряд, 500 на 30-й день и 1500 на 100-й.
- При заявке на бонус баллы списываются сразу. Если учитель отклоняет заявку, они возвращаются.
- Уровень зависит от всех заработанных баллов, поэтому траты его не снижают. Каждые 50 баллов дают новый уровень.
- Серия «Импульс» считает дни подряд с пройденным тестом. Один пропущенный день в неделю серию не обрывает.
- Значки выдаются за тест без ошибок и за серии в 7, 30 и 100 дней.

| Бонус | Стоимость | Ограничение |
| --- | --- | --- |
| Выбрать тему для обсуждения на уроке | 400 | раз в 30 дней |
| Сертификат «Эксперт темы» | 800 | раз в 30 дней |
| Отмена двойки за одну домашнюю работу | 1500 | раз в 63 дня |
| Оценка за регулярную самостоятельную работу | 2500 | раз в 63 дня |
| Звание в чате класса | 4000 | нет |

Стоимость рассчитана Софией К. для активного ученика, который зарабатывает около 600 баллов в неделю.

| Звание | С какого уровня |
| --- | --- |
| Новичок | 1 |
| Исследователь | 10 |
| Эрудит | 20 |
| Магистр | 40 |
| Архимаг | 65 |
| Гуру | 100 |

Предметные оценки бот не меняет: бонусы выдаёт учитель по правилам школы.

## Тест из Excel

Учитель открывает «Тесты», «Создать свой тест», вводит название и отправляет файл `.xlsx` до 5 МБ и до 200 вопросов. Образец можно скачать кнопкой в боте или взять [test_template.xlsx](test_template.xlsx).

| № | Вопрос и варианты | Ответ | Пояснение | Сложность |
| --- | --- | --- | --- | --- |
| 1 | Сколько будет 2 + 2? А) 3 Б) 4 В) 5 Г) 6 | б | 2 + 2 = 4 | 1 |

Готовые блоки программы добавляются файлами в папку [catalog](catalog/README.md) и появляются в разделе «Тесты по темам». Варианты удобнее писать каждый с новой строки. Варианты перемешиваются, поэтому не используйте ответы вроде «все перечисленные» или «А и Б».

Стек: Python 3.12, [maxapi](https://pypi.org/project/maxapi/1.2.3/), SQLite, Docker. Бот получает события через long polling, поэтому открытые порты не нужны.

Как проходит тест:

1. Учитель выдаёт тест, бот сохраняет срок и рассылает приглашения.
2. Ученик начинает тест: фиксируется время старта и личный порядок вопросов.
3. Каждый ответ и баллы сохраняются в одной транзакции, поэтому после сбоя можно продолжить с того же места.
4. Фоновая задача раз в 30 секунд завершает прохождения с истёкшим временем и закрывает тесты.
5. При закрытии ученики получают разбор, учитель получает отчёт.

## Безопасность

- Пароли хранятся только в виде хеша bcrypt, бот старается удалить сообщение с паролем из чата.
- После пяти неудачных попыток вход и ввод кодов блокируются на 5 минут.
- Регистрация учителя защищена кодом.
- Токен и база исключены из репозитория через `.gitignore`.
- Во время теста бот не сообщает, верен ли ответ. Ученик видит только итог, а правильные ответы открываются после закрытия теста.
- Excel-файлы проверяются по размеру и структуре, загружаются только с публичных адресов.
- Контейнер работает от непривилегированного пользователя.
- Бот хранит только ФИО, идентификатор MAX и учебные результаты. Базу с данными нельзя публиковать.

## Ограничения

- Рассчитан на один запущенный экземпляр и одну базу SQLite.
- Шаги диалогов хранятся в памяти: незавершённое создание класса или импорт после перезапуска нужно начать заново. Вход, ответы и баллы сохраняются.
- ФИО уникально в базе. Если его занял другой человек, нужна помощь администратора.
- Восстановления пароля через бота нет, но после входа бот узнаёт пользователя по аккаунту MAX.
- Редактирования классов и тестов через меню пока нет, как и выгрузки результатов в файл.
